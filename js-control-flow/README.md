# JavaScript Control Flow Lab

## Overview

This repository contains the implementation of core JavaScript control flow structures: conditional statements, loops, and functions. The script is designed to be executed directly in a Node.js environment via the terminal.

## Implementation Details

1. **Conditional Statements (`if`, `else if`, `else`)**:
   - Implemented an `evaluateTemperature` function that branches its return value based on numeric temperature inputs.
   - Successfully demonstrated decision-making by producing different string outputs for varying input values.
2. **Loops (`for`)**:
   - Utilized a `for` loop to execute a repeated task, specifically generating a sequential countdown in the console.
3. **Functions**:
   - Created a reusable `calculateDiscount` mathematical function that accepts dynamic arguments (`price` and `discountPercentage`) and accurately returns the computed result.

## How to Run

Ensure Node.js is installed on your machine.

1. Clone the repository.
2. Navigate to the project directory.
3. Run the following command in the terminal:
   `node script.js`
